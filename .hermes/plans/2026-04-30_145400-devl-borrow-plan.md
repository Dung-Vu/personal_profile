**Mục tiêu:** Thêm chart visualization cho StackPage (skill breakdown) mà không cần thư viện nặng.

#### 4.1. Pattern tham khảo từ devl.dev
- **donut** — ring chart cho tỉ lệ phần trăm
- **bar** — horizontal bar chart cho so sánh
- **gauge** — semicircle gauge cho mức độ thành thạo
- **sparkline** — mini chart không axis, cho trend

#### 4.2. Components

| Component | File | Dùng ở đâu |

| `Sparkline` | `src/components/ui/Sparkline.jsx` | HomePage — mini trend line |

#### 4.3. Cách triển khai
- **Pure SVG** inline trong React component
- Dùng `stroke-dasharray` + `stroke-dashoffset` cho ring chart

**Mục tiêu:** Thêm command palette (⌘K) để navigate nhanh + các tiểu tiết UX.

#### 5.1. Pattern tham khảo từ devl.dev
- **Command palette** — ⌘K mở search, gõ để filter, ↑↓ để chọn, Enter để đi
- **Keyboard shortcut hints** — hiển thị phím tắt trong UI (ví dụ: `esc back · ← → browse`)
- **Toast** — notification nhỏ ở góc, tự biến mất

#### 5.2. Components

| Component | File | Mô tả |
|---|---|---|
| `CommandPalette` | `src/components/ui/CommandPalette.jsx` | ⌘K mở, search route, navigate |
| `Toast` | `src/components/ui/Toast.jsx` | Notification toast (success/error/info) |
| `ToastContainer` | `src/components/ui/ToastContainer.jsx` | Stack nhiều toast |

#### 5.3. Command Palette behavior
- Kích hoạt: `Ctrl+K` / `⌘K`
- Hiển thị: overlay tối + panel giữa màn hình
- Search: gõ để filter route + action
- Navigate: ↑↓ chọn, Enter đi, Esc đóng
- Các action mặc định: "Về trang chủ", "Xem case studies", "Liên hệ", "Đổi theme", "Mở Lab"

## 6. Quy tắc triển khai

1. **Viết custom CSS, không cài thư viện** — tận dụng CSS custom properties + GSAP hiện có
2. **Giữ nguyên design tokens** — chỉ thêm, không sửa token cũ
3. **Không thay đổi layout structure** — SiteShell, Header, Footer, ProgressRail giữ nguyên
4. **Browser QA sau mỗi phase** — mở dev server, verify visual trên ít nhất 3 route
5. **Mobile-first responsive** — test trên viewport 375px, 768px, 1440px
6. **Respect reduced-motion** — người dùng bật `prefers-reduced-motion` thì animation disable
7. **Không thay đổi nội dung** — chỉ thay đổi cách hiển thị, không sửa text/data

## 7. Risk & mitigation

| Risk | Impact | Mitigation |
|---|---|---|
| CSS specificity conflict với style hiện tại | Layout vỡ | Test trên tất cả route sau mỗi phase |
| GSAP animation conflict với component mới | Animation lỗi | Dùng `ScrollTrigger.refresh()` sau khi mount |
| Custom cursor conflict với command palette | Cursor không hiển thị đúng | Tạm disable custom cursor khi palette mở |
| Performance regression từ nhiều animation | Jank trên mobile | Dùng `will-change` sparingly, test trên mobile thật |
| Icon thiếu (Lucide React không có) | UI không đồng nhất | Dùng SVG inline thay vì Lucide nếu cần |
